# Call Analyzer Bot

Аналізатор дзвінків клієнтів з СТО. Скрипт транскрибує аудіофайли розмов через Deepgram та аналізує їх через Groq LLM з виставленням балів та занесенням результатів до локальної CSV-таблиці.

## Структура проекту

```
call-analyzer-bot/
│
├── data/
│   ├── incoming_calls/        # Папка з вхідними аудіофайлами (.mp3)
│   └── Лист1.csv               # Локальний CSV-звіт з результатами аналізу
│
├── src/
│   ├── __init__.py
│   ├── transcriber.py         # Модуль транскрибації через Deepgram (Nova-2)
│   ├── analyzer.py            # Модуль аналізу розмов через Groq (Llama 3.1)
│   └── csv_manager.py         # Запис результатів у локальний CSV файл
│
├── .env                       # Конфігураційний файл з API ключами
├── .env.example               # Приклад конфігураційного файлу
├── .gitignore                 # Ігнорування секретних та тимчасових файлів
├── main.py                    # Головний скрипт запуску
├── README.md                  # Інструкція з запуску
└── requirements.txt           # Залежності проекту
```

## Налаштування та запуск

1. Створіть файл `.env` на основі `.env.example` та вкажіть ваші ключі:
   ```env
   GROQ_API_KEY=your_groq_api_key
   DEEPGRAM_API_KEY=your_deepgram_api_key
   ```
2. Помістіть `.mp3` файли для аналізу в папку `data/incoming_calls/`.
3. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустіть скрипт:
   ```bash
   python main.py
   ```
5. Звіт буде збережено в `data/Лист1.csv`, а розшифровки дзвінків — у `.txt` поруч з оригінальними аудіофайлами.
